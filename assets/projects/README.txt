Project screenshots go here.

1. Save a 16:10 image (e.g. 1600x1000), ideally .webp or .jpg under ~200 KB.
2. In js/content.js, set the project's image, e.g.  image: "assets/projects/gcid.webp"
3. Run:  node tools/render.mjs

Until then each card shows a styled placeholder of the same size, so nothing shifts.
